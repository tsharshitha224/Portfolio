Citizen Fraud Shield: RAG-Powered Scam Analysis Chatbot

A high-speed RAG-based cybersecurity assistant that analyzes citizen-reported suspicious calls, SMS phishing, and social engineering attempts in real time, returning immediate risk scoring, scam taxonomy, and proactive defense instructions.

01 // Problem Space

The Escalating Threat of Hyper-Personalized Scams

Digital financial fraud, fake KYC suspension alerts, impersonation schemes, and AI voice cloning have grown exponentially. Everyday citizens, especially elderly individuals and students, often struggle to evaluate whether an urgent message from "their bank" or "courier service" is genuine.

Traditional static scam blacklists fail because fraudsters generate new burner phone numbers and domain permutations within minutes. What citizens need is contextual semantic comprehension that analyzes the manipulative psychology and intent behind any incoming message.

02 // RAG Architecture

Hybrid Semantic Retrieval & High-Speed Reasoning

Citizen Fraud Shield utilizes a Retrieval-Augmented Generation (RAG) architecture. When a user pastes a suspicious message or call transcript, the system creates vector embeddings using Sentence-Transformers and queries a continuously updated ChromaDB knowledge store of verified cybercrime FIRs, known scam templates, and banking security advisories.

Sub-Second Analysis via Groq Llama 3.3

By running inference on Groq's high-throughput LPU hardware, our system generates a complete threat risk score (0–100%), flags scam psychological tactics (urgency, fear, greed, fake authority), and outputs tailored emergency defense actions in under 600ms.

  • Instant Threat Score (0–100): Clear, color-coded risk assessment allowing users to make instantaneous decisions.
  • Scam Taxonomy Categorization: Identifies specific fraud vectors (e.g., Fake Electricity Bill, Part-Time Job Scam, Digital Arrest, Lottery Phishing).
  • Actionable Protection Protocol: Step-by-step guidance on which cybercrime portal to report to (e.g., 1930 / cybercrime.gov.in) and how to freeze affected accounts immediately.
  • Privacy-Preserving Pre-processing: Redacts sensitive PII (passwords, bank numbers, names) client-side before semantic vector processing.
03 // Technical Specifications

Technology & Pipeline Stack

LLM Reasoning

Groq API powering Llama 3.3 for lightning-fast structured JSON output and safety deduction.

Vector Database

ChromaDB for dense semantic indexing and cosine-similarity neighbor queries against scam databases.

Embeddings Model

HuggingFace Sentence-Transformers (all-MiniLM-L6-v2) for compact, high-efficiency text vectors.

Asynchronous API

FastAPI backend with Pydantic schema validation, rate-limiting, and non-blocking I/O.

Democratizing Cyber Safety for Everyone

Designed with simplicity and empathy at its core, Citizen Fraud Shield removes technical jargon and acts as a trusted digital guardian. Future enhancements include voice-call speech-to-text pipeline for automated live scam call filtering and multi-lingual regional Indian language dialect support.
