# Harshitha Suresh — Bespoke Creative Developer Portfolio

An award-winning editorial portfolio crafted with bespoke artistry, mechanical tactility, and contemporary creative development techniques.

---

## 🎨 Color System (Classic Palette)

- **Ivory (`#F7F3EB`)**: Warm, premium paper-like background surface.
- **Burgundy (`#7D263A`)**: Rich luxury accent for calls to action, headings, and highlights.
- **Charcoal (`#25221F`)**: Deep high-contrast tone for typography and structural framing.

---

## 🏛️ Design Influences & Technical Architecture

1. **Meet Vora — Preloader (0–100%) & Kinetic Typography**:
   - Numerical counter ticking from 00 to 100% paired with `"Design. Create. Innovate."` typography and a smooth upward curtain reveal.
2. **Tim Quirino — Hero Hierarchy & Magnetic Precision Cursor**:
   - Editorial headline typography for `"Harshitha Suresh"` and subtitle `"Design. Create. Innovate."`.
   - Precision custom cursor with elastic lag physics and magnetic snapping to navigation.
3. **Zhenya Rynzhuk — Color Collision View Transitions**:
   - Two graphic spheres (Burgundy and Charcoal/Ivory) collide at the screen center with a physical squish & splash wave before transitioning views.
4. **Meet Vora — Tactile Experience Orbit Wheel**:
   - Draggable, interactive circular orbit featuring 8 internship and leadership roles (including UBA & Red Ribbon Club with MAGIC explanation).
5. **Thibaut Crépelle — 3D Mechanical Keyboard Console**:
   - Fully interactive mechanical keyboard with realistic keycaps, press animations, Web Audio API click sound synthesizer, and real-time typed notes screen.
6. **Dedicated Project Case Study Pages**:
   - Individual standalone pages for:
     - `projects/carbon-trading.html` (DLT Blockchain Carbon Credit Platform)
     - `projects/smart-surveillance.html` (SIH 2023 CCTV Crowd & Crime AI/ML)
     - `projects/citizen-fraud-shield.html` (Citizen Fraud Shield RAG AI Chatbot)

## 🐙 Git Deployment Guide

To link and push this repository to your GitHub account:

```bash
# 1. Rename branch to main (recommended)
git branch -M main

# 2. Add your remote repository URL
git remote add origin https://github.com/HarshithaSuresh-22/portfolio.git

# 3. Push all commits to GitHub
git push -u origin main
```
