01 // Problem Space

The Blind Spots in Urban Public Surveillance

Metropolitan cities operate tens of thousands of CCTV feeds. However, more than 95% of these cameras are passively recorded without active human monitoring due to personnel fatigue. In critical high-density junctions (railway hubs, pilgrimage sites, festival grounds), stampedes and crimes occur before security operators can manually identify the bottleneck.

Installing specialized AI sensors across millions of street poles is economically unviable. The challenge was: Can we make existing, low-resolution RTSP CCTV cameras intelligent through edge AI algorithms without purchasing new hardware?

02 // Deep Learning Pipeline

Multi-Stream Object Detection & Anomaly Recognition

We engineered a modular inference pipeline capable of ingesting multiple RTSP video streams simultaneously. Frames are processed through a customized YOLOv8 architecture optimized with TensorRT for low latency.

Key Breakthrough: Real-Time Dynamic Heatmapping

Rather than simply counting heads, our pipeline generates perspective-corrected crowd density heatmaps. When density per square meter crosses critical safety thresholds, automated audio-visual alerts are dispatched to nearby station controllers.

  • Crowd Density & Chokepoint Alerts: Predicts crowd surge velocity to prevent stampedes before density becomes dangerous.
  • Unattended Luggage & Object Detection: Spatially correlates stationary bounding boxes over time to flag suspicious abandoned bags in transit zones.
  • Workforce & Patrol Monitoring: Verifies active security presence in assigned perimeter zones during night shifts.
  • Centralized Operator Web Dashboard: Unified multi-camera console built with Flask/Django streaming video feeds with overlay telemetry.
03 // Technical Specifications

Model Architecture & Tech Stack

Computer Vision Models

YOLO, custom CNN layers, and PyTorch transfer learning models optimized for pedestrian tracking and motion vectors.

Video Ingestion

OpenCV video capture engine handling multi-threaded RTSP IP camera decoding and downsampling.

Server Backend

Python with Flask & Django handling WebSocket alert streams, user permissions, and event logging.

Frontend UI

Responsive multi-tile camera monitoring interface crafted in HTML5, CSS3, and JavaScript.
